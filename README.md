# 🎬 KEMSININ AI DUBBER (Android App & Cloud Engine)

KEMSININ Dubber is a mobile AI application and automated video dubbing pipeline for Android and desktop.

## ✨ Features
* 🎙️ **Speech to Text**: Multi-lingual transcription with timestamps.
* 🤖 **Gemini AI Translation**: Intelligent subtitle contextual translation directly to Khmer and other languages.
* 🗣️ **Neural Voice Synthesis**: Edge-TTS natural Khmer voice generation (Piseth & Sreymom).
* 🔄 **Audio & Subtitle Sync**: Automatic speed adjustment and timeline alignment.
* 📱 **Jetpack Compose UI**: Modern, responsive dark-mode mobile interface.
* 🚀 **Automated CI/CD**: Builds Android APK automatically on GitHub Actions!

## 📦 Download APK
Every push to `main` generates release APKs automatically in [GitHub Actions / Releases](https://github.com/kemsinin0001-lgtm/KEMSININ_DUBBER/actions).
